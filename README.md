# Meridiano

Sito dimostrativo per un ristorante immaginario di cucina emiliana nel centro di Modena.

**Online:** https://frnc1.github.io/meridiano/

## Cosa fa

- In cima alla pagina, una meridiana segue l’ora di Modena: mostra i servizi della giornata e dice se il locale è aperto.
- Il menu d’autunno è diviso per portate, con prezzi, percorso degustazione e indicazioni per chi ha allergie.
- Il modulo di prenotazione propone solo gli orari del giorno scelto e segnala il lunedì di chiusura. È dimostrativo: non invia nulla.
- Si adatta a telefono, tablet e computer.
- Nessun cookie e nessuna richiesta a servizi esterni: anche il carattere tipografico è ospitato insieme al sito.

## Come è fatto

Un solo file HTML con CSS e JavaScript, senza framework e senza passaggi di compilazione. È pubblicato con GitHub Pages.
